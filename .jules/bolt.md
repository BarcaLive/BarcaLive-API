## 2024-05-24 - O(N) Hash Map Deduplication and Single-Pass Categorization
**Learning:** In the `src/match.js` file, match deduplication was originally implemented using an O(N²) approach (`allMatchesRaw.find` nested inside a `for` loop). This created a hidden performance bottleneck as the number of external matches scales. Furthermore, three separate `Array.prototype.filter` calls were made on the same list of unique matches, which caused unnecessary repeated iterations.
**Action:** Replace nested loops that involve array lookups (`.find`, `.includes` for large lists) with an O(N) Hash Map implementation (`Map`) during deduplication, and refactor sequential `.filter()` operations into a single O(N) `for...of` loop to save processing time and resources. Keep a close eye on where array operations might stack up latency in data transformation pipelines.
